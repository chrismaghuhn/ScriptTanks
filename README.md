# ScriptTanks

ScriptTanks is a programming autobattler where the player builds and programs autonomous tanks.

## Projects

- `src/ScriptTanks.Core` — deterministic simulation core
- `tests/ScriptTanks.Core.Tests` — automated tests for the core
- `script-tanks/` — current Godot client project
- `docs/` — lightweight documentation entrypoint
- `ScriptTanks_Document_Package/` — full design and planning documentation

## Build

```bash
dotnet build ScriptTanks.sln
dotnet test ScriptTanks.sln
```
