# Security policy

## Supported versions

Only the active development branch of this repository is supported. There are no long-term maintained release branches at this time.

## Reporting a vulnerability

If you believe you have found a security issue:

1. **Preferred:** Open a [GitHub Security Advisory](https://github.com/chrismaghuhn/ScriptTanks/security/advisories/new) (private report).
2. **Alternative:** Open a GitHub issue with minimal public detail and ask for a private channel to share specifics.

Please do not post exploit details publicly before a fix is available.

## Scope

This policy applies to the ScriptTanks repository (simulation core, tests, documentation, and CI configuration). It does not cover third-party services or the Godot engine itself.

## Response

Maintainers will acknowledge reports as soon as practical. There is no bug bounty program.
